# thiele-research-public

The public-visibility subset of the debate research methodology and wiki.

**Status:** plumbing only. `schema/` in the source repo (`research_base`) is
scaffolded but not yet populated — the methodology it will hold currently
exists only in a separate chat session's memory and hasn't been exported to
files yet. Nothing to publish until that export happens.

Once `schema/` and `wiki/` (with `visibility: public` frontmatter) have real
content, this repo will hold the exported public subset — content reusable
by someone who isn't the author: highlighting rules, topicality taxonomy,
argument model. Not the episodic record (which card beat which, round
results) — that stays private.
